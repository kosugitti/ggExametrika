# Apply legend visibility and position to a ggplot

Apply legend visibility and position to a ggplot

## Usage

``` r
.apply_legend(p, show_legend, legend_position)
```

## Arguments

- p:

  A ggplot object.

- show_legend:

  Logical. FALSE hides the legend.

- legend_position:

  Legend position passed to
  [`theme()`](https://ggplot2.tidyverse.org/reference/theme.html).

## Value

The modified ggplot object.
