# Inverse of .variable_scaler for secondary-axis labeling

Inverse of .variable_scaler for secondary-axis labeling

## Usage

``` r
.axis_scaler(y1, yaxis1, yaxis2)
```

## Arguments

- y1:

  Values on the primary scale.

- yaxis1:

  Range (min, max) of the primary axis.

- yaxis2:

  Range (min, max) of the secondary axis.

## Value

`y1` linearly mapped into secondary-axis coordinates.
